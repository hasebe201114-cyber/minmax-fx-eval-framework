## 注意事項・引っかかりポイント

- **Mavis 環境での C 査読の独立性**: 物理的に単一 LLM のため、独立 adversarial review は擬似的にしか確保できない。**この制約を明示的に開示**し、最終 GO は司令塔判断に委ねる
- **DSR の N (試行数) の数え方**: 19-28 試行は「保存された spec 改訂の数」と「実際に試したパラメータ組み合わせ」の両方をどう合算するかで解釈が変わる。Bailey 2014 は conservative に「より大きい N」を推奨
- **permutation.py の typo**: 親 PJ 側の `PAIR_CORRELATION_MATRIX` に GBP_JPY のキー typo があった（`"GBP_JPY": {... "GBP_JPY": 1.0, ...}` となるべきだが、`"EUR_JPY"` になっている）。本 PJ 側の fork にも引き継がれているため、後で修正必要
- **テスト未実行**: 本セッションでは実装のみで `pytest` 実行は未検証。次セッションで実行確認
