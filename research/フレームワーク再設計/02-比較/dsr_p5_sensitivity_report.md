## 2. 閾値感度

v0.3 spec での p5 ≥ 0.95 は「最も厳しすぎる」閾値の一つ。**4 戦略中 0 戦略のみ通過**。

段階的に閾値を下げた場合の含意:

### 2.1 p5 ≥ 0.95 (現行 v0.3 必須ゲート)
- **通過戦略**: 0/4
- **効果**: 全戦略を却下。SYS-FX011 T-13 のような「p5=0.9085」の戦略も通らない
- **妥当性**: 厳しすぎ。SYS-FX011 T-13 は p50=0.9941 なので中央値では十分だが、
  p5（ワーストケース寄り）だと 0.95 ギリギリ届かない

### 2.2 p5 ≥ 0.90 (1 段緩和案)
- **通過戦略**: 1/4 (SYS-FX011 T-13 のみ)
- **効果**: 「p50 でほぼ PASS、p5 で惜敗」程度の戦略を救う
- **妥当性**: SYS-FX011 T-13 は n=827 トレード (n_hard_floor=60 を大幅超過)、
  ランダム化 100 サンプルで mean=0.9773 ± 0.0420 → 安定。**p5 ≥ 0.90 緩和は妥当**

### 2.3 p5 ≥ 0.85 (大幅緩和案)
- **通過戦略**: 2/4 (SYS-FX009 v2, SYS-FX011 T-13)
- **妥当性**: SYS-FX009 v2 は「陳腐化シグナル回転売買バグ修正後のクリーンな結果」だが
  perm_p 0.271/0.774/0.474 と有意性弱。**p5=0.8997 で 0.85 を辛うじて通過**。
  本格採用は危うい。

### 2.4 p5 ≥ 0.80 (参考)
- **通過戦略**: 2/4 (SYS-FX009 v2, SYS-FX011 T-13)
- **妥当性**: 0.85 と同じ戦略が通過。差異なし。

## 3. 推奨アクション

**案 A (推奨)**: 現行 v0.3 閾値 p5 ≥ 0.95 を維持しつつ、**p5 ≥ 0.90 を「参考値」枠**として併記。
- DSR_PASS_CAP=5/年 で頭打ちするので実質的な影響は限定的
- 司令塔が個別判断する際の材料を提供

**案 B**: p5 ≥ 0.95 → p5 ≥ 0.90 に緩和 (SYS-FX011 T-13 を救済)
- 統計的検出力は 0.90 でも十分 (Bailey 2014 §4.3 で言及)
- ただし M-S1 (DSR 必須化) 自体が「緩い」批判を受けるリスク

**案 C**: 段階的ゲート化 (p5 ≥ 0.90 で条件付き PASS、フォワードテスト併用必須)
- 検証 → フォワードテスト → 本番の 3 段階で評価
- 既存の SYS-FX012 フォワードテスト設計と整合
